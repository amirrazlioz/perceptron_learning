🧠 אלגוריתם הלמידה של הפרספטרון

הפרספטרון לומד מטעויות: הוא בודק נקודה אחרי נקודה, ובכל פעם שהוא טועה – הוא מזיז את הקו.

🔵 כחול = 1  |  🔴 אדום = 0  |  ◌ מקווקו = הקו הנוכחי טועה בנקודה  |  🟡 טבעת = הנקודה הנבדקת  |  החץ w = הכיוון ה"כחול" של הקו

📋 האלגוריתם

אתחול: w = 0 , b = 0
כל עוד לא כל הדוגמאות מסווגות נכון:
לכל דוגמה (x, y):
  1. מחשבים z = w·x + b
    ומחזים:
    אם z ≥ 0  ⇒  ŷ = 1
    אם z < 0  ⇒  ŷ = 0
  2. אם y = 1 אבל ŷ = 0:
    w = w + x   b = b + 1
  3. אם y = 0 אבל ŷ = 1:
    w = w − x   b = b − 1
  4. חוזרים על כל הדוגמאות (סבב), עד שיש סבב שלם בלי אף טעות.
